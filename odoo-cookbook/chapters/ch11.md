## Core Concepts

- **Translation mechanism**: Odoo extracts `_()` wrapper calls, field string/help attributes, and report labels into `.pot` files.
- **Language installation**: Settings → Languages → Add/Remove Languages. Each language creates `ir.translation` records.

## Techniques

- **Export translations**: Technical → Translations → Export Translation — selects untranslated or all entries. Format: `.po` (gettext) or `.csv`.
- **Import translations**: Technical → Translations → Import Translation — upload `.po` or `.csv`.
- **Module `.po` files**: Place in `i18n/` directory with language code naming (e.g., `fr.po`, `de.po`). Loaded on module install.
- **Gettext tools**: Use `msgmerge`, `msgfmt` for PO file management. `msgmerge` merges new template with existing translations.
- **Website language URL**: `website_id.default_lang_code` in multi-website setup — each website can serve a different language.

## Pitfalls

- Untranslated fields show the English label/string — no fallback mechanism.
- Stage names and selection labels are translatable — can break domain-based logic.
