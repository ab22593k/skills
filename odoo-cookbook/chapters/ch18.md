## Core Concepts

- **Prefetching**: ORM fetches all fields for all records in a recordset on first field access — O(1) queries instead of O(n). Disable with `prefetch_fields=False` context when harmful.
- **`@tools.ormcache`**: LRU in-memory cache. Keyed by arguments — if every call has unique args, overhead exceeds benefit.
- **`image.mixin`**: Mixin adding `image_1920`, `image_1024`, `image_512`, `image_256`, `image_128` fields. Smaller images auto-generated from `image_1920`.

## Techniques

- **Bulk create**: `model.create([{vals1}, {vals2}, ...])` — single SQL INSERT for all records.
- **Bulk write**: `records.write({field: value})` — single UPDATE for all records.
- **`_read_group()`**: SQL GROUP BY aggregation — much faster than Python-level grouping for large datasets.
- **Profiler**: Technical → Profiling. Enables per-request SQL, time, memory tracking. Send `SIGUSR1` to dump cache stats to logs.
- **Database queries**: `self.env.cr.execute()` with re-filtering through ORM for bulk operations.
- **Split recordsets with shared prefetch**: `.with_prefetch(recordset._ids)` avoids redundant queries across split subsets.
- **Clear cache**: `self.env[model].clear_caches()` — use sparingly.

## Pitfalls

- `@ormcache` methods must NEVER return a recordset — cursor closure causes `psycopg2.OperationalError`.
- Prefetching unused fields wastes memory — benchmark before optimizing.
- LRU cache eviction drops infrequently used keys automatically; monitor with SIGUSR1.
