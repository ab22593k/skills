## Core Concepts

- **IoT Box**: Dedicated hardware (Raspberry Pi 3 B+) running Odoo's IoT operating system. Connects peripheral devices (printers, scales, barcode scanners, payment terminals) to Odoo POS.
- **Communication**: Odoo server ↔ IoT Box via REST API over LAN. IoT Box auto-registers with the Odoo instance.

## Techniques

1. **Flash image**: Download Odoo's IoT image, flash to SD card via `dd` or Raspberry Pi Imager.
2. **Network connect**: Connect via Ethernet or Wi-Fi (configure `wpa_supplicant.conf`). Find IP via router DHCP list or mDNS.
3. **Add to Odoo**: Settings → IoT → Add IoT Box — enter IP. Odoo discovers drivers and devices automatically.
4. **Load drivers**: IoT Box auto-loads HID/USB drivers. Manual: `iot.remote.driver` model for custom drivers.
5. **Device input**: Scale weight, barcode scan → `/iot/input` route processes and pushes to POS session.
6. **SSH access**: `ssh root@<iot-ip>` (default password on IoT image). Configure password or SSH keys.
7. **PDF to printer**: Use `escpos` protocol for thermal printers. Configure in POS settings.

## Pitfalls

- IoT Box is Enterprise-only — not available in Community Edition.
- IoT image must match Odoo server version — mismatches cause connection failures.
- Default SSH password is well-known — change immediately in production.
