## Core Concepts

- **XML-RPC endpoint**: `/<db>/xmlrpc/2/common` (auth/version) and `/<db>/xmlrpc/2/object` (data). Protocol: `xmlrpc.client.ServerProxy`.
- **JSON-RPC endpoint**: POST `/<db>/jsonrpc` with `{"jsonrpc":"2.0", "method":"call", "params":{"service":"object","method":"execute_kw","args":[...]}}`.
- **Deprecation**: Both XML-RPC and JSON-RPC external APIs are deprecated in Odoo 19, scheduled for removal in Odoo 22. Use The **External JSON-2 API** (`odoo-client-lib`) going forward.

## Techniques

- **XML-RPC auth**: `client.ServerProxy(url + '/xmlrpc/2/common').authenticate(db, user, password, {})` → `uid`.
- **XML-RPC CRUD**: `models.execute_kw(db, uid, password, model, 'search', [domain], {kwargs})`. `search_read` as combined call.
- **JSON-RPC payload**: Helper builds `{"jsonrpc":"2.0","method":"call","params":{"service":"object","method":"execute_kw","args":[db, uid, pw, model, method, args, kwargs]},"id":random()}`.
- **OCA odoorpc**: `odoorpc.ODOO(host, port=8069, protocol='jsonrpc')` — ORM-like interface: `api.env['res.partner'].search([])`.
- **REST API controller**: `@http.route('/api/v1/...', type='json', auth='token', methods=['GET','POST'])` + manual credential validation.
- **API keys**: User → Preferences → Account Security → New API Key. Displayed once. Replace password in RPC calls.

## Pitfalls

- API keys shown once only — regenerate if lost.
- Only public methods (no leading `_`) are callable via RPC.
- Hardcoding credentials in scripts = security risk — use environment variables.
