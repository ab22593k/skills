# AGENTS.md

This is a skills repository — a library of Claude Code / OpenCode skills and the tooling to create and evaluate them.

## Key directories

- `.agents/skills/` — local skills (skill-creator, trigger-test-\*, others)
- `book-to-skill/` — skill for converting PDFs/EPUBs to Claude Code skills
- `engineering/` — domain skills (testing, latency, performance, etc.)
- `rust/` — Rust-specific skills (idiomatic, kernel, modern, refactoring)
- `design/` — design skills (expressive)
- `.agents/skills/skill-creator/` — **primary tooling for skill authoring**

## Skill-creator scripts (`.agents/skills/skill-creator/scripts/`)

```bash
# Generate eval viewer for human review
python .agents/skills/skill-creator/eval-viewer/generate_review.py <workspace>/iteration-N --skill-name <name> [--previous-workspace <prev>]

# Aggregate grading results into benchmark.json
python -m scripts.aggregate_benchmark <workspace>/iteration-N --skill-name <name>

# Package skill as distributable .skill file
python .agents/skills/skill-creator/scripts/package_skill.py <skill-folder> [output-dir]

# Run trigger optimization loop (requires claude CLI + ANTHROPIC_API_KEY)
python -m scripts.run_loop --eval-set <trigger-eval.json> --skill-path <path> --model <model-id> --max-iterations 5
```

## Skill anatomy

```
skill-name/
├── SKILL.md          (required) — name + description in YAML frontmatter
├── evals/evals.json  (optional) — test cases
├── scripts/          (optional) — bundled executables
├── references/       (optional) — on-demand docs
└── assets/           (optional) — templates, icons, fonts
```

## Eval workspace layout

Runs go into a sibling `<skill-name>-workspace/` directory:

```
iteration-N/
├── eval-0/
│   ├── with_skill/outputs/   + grading.json + timing.json
│   └── without_skill/outputs/ + grading.json + timing.json
├── eval_metadata.json
└── benchmark.json  (generated by aggregate_benchmark.py)
```

## JSON schemas (critical field names)

- `grading.json` expectations: `text`, `passed`, `evidence` — the viewer reads these exact names
- `benchmark.json` run configuration: use `"with_skill"` / `"without_skill"` — not `config` or other variants
- `timing.json`: save immediately when subagent notifications arrive (`total_tokens`, `duration_ms`) — not persisted elsewhere

## Eval files (`evals/evals.json`)

```json
{
  "skill_name": "example-skill",
  "evals": [
    {
      "id": 1,
      "prompt": "User task prompt",
      "expected_output": "Description",
      "files": [],
      "expectations": ["Verifiable statement 1", "Verifiable statement 2"]
    }
  ]
}
```

## Subagent instructions

- `agents/grader.md` — how to grade assertions and write grading.json
- `agents/comparator.md` — blind A/B comparison between two outputs
- `agents/analyzer.md` — post-hoc analysis of comparison results and benchmark patterns

## Trigger eval (description optimization)

1. Generate 20 queries (8-10 should-trigger, 8-10 should-not-trigger) — realistic, not abstract
2. Review with user via `assets/eval_review.html` → export to `eval_set.json`
3. Run `scripts/run_loop.py` in background — check progress periodically
4. Apply `best_description` from output to SKILL.md frontmatter
