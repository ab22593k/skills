# UI and UX Design

## Core concepts

- AI tools compress design-to-code from weeks to hours. Two categories: **ideas-to-designs** (Uizard, Galileo AI) and **designs-to-code** (Bolt.new, Lovable).
- The dominant emerging pattern is generating both design AND working code from a single natural-language prompt (Bolt.new, Lovable both rated 10/10).
- Software engineers can now own more of the design workflow — not just implementing designs but creating them.

## Frameworks introduced

**No-design paradigm** — Uizard's slogan "Forget no-code, here comes no-design." The analogy: just as no-code automated implementation, AI tools can now automate the design phase. This shifts the engineer's role toward understanding user needs and iterating on designs rather than creating pixel-perfect mockups.

**Design-to-code compression** — The traditional workflow (wireframe → mockup → prototype → frontend code → backend integration) collapses to: prompt → working app. Tools like Bolt.new generate TypeScript frontend, provide a preview, and deploy in one flow.

## Key techniques

**Rapid prototyping:** Use Uizard for interactive demos without writing code. Use Bolt.new or Lovable for production-grade frontend code from prompts.

**UX research automation:** Use QoQo.ai (Figma plugin) for personas, journey maps. Use Research Studio to extract insights from user interviews and survey responses.
