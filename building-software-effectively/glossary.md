**agentic mode** — AI tool mode that autonomously creates files, installs dependencies, and modifies code without step-by-step confirmation. Windsurf's Cascade is the prime example. (Ch 1)

**AI + Human principle** — The book's core thesis: AI automates repetitive grunt work while humans provide context, judgment, and quality control. Neither works effectively alone. (Ch 1, 8)

**black box effect** — When AI tools produce polished outputs from large datasets, making errors hard to spot without independent verification. Common in data analysis and forecasting. (Ch 5)

**browser-based tools** — AI tools accessed via website (ChatGPT, Gemini). Convenient but limited by manual context sharing and copy/paste workflow. (Ch 1)

**Cascade** — Windsurf's flagship agentic feature. Acts as an independent coding agent that anticipates needs, debugs, and edits multiple files. (Ch 1)

**code review** — Process of reviewing code changes before merging. AI tools automate this with security scanning, style enforcement, and fix suggestions. (Ch 3)

**design-to-code compression** — AI tools reducing the traditional multi-week design-to-implementation pipeline to hours by generating both designs and working code from prompts. (Ch 2)

**hallucination** — LLM output that is factually incorrect, makes up API endpoints, or contains logical errors. Pervasive risk across all AI tools. (Ch 1, 5, 7)

**IDE-based tools** — AI tools embedded in the development environment (Cursor, Copilot, Windsurf). Ingest full codebase as context and make changes in-place. (Ch 1)

**LangChain** — Most popular framework for building LLM-powered applications and AI agents. Supports multi-agent workflows via LangGraph. (Ch 7)

**no-design** — Uizard's concept: just as no-code automated implementation, AI now automates the design phase. Non-designers can create interfaces from prompts. (Ch 2)

**Pareto principle in QA** — 20% of testing effort (defining workflows and acceptance criteria) creates 80% of value. AI handles the remaining 80% of grunt work. (Ch 4)

**Planning-Prompting-Review workflow** — Shopify's three-phase process: write detailed prompt, let AI code, double down on review. The disciplined alternative to vibe coding. (Ch 8)

**prompt engineering** — Crafting detailed, context-rich prompts that include requirements, coding standards, and edge cases to guide AI output. (Ch 1, 8)

**regression** — When a feature is sent back from review or QA to the developer for fixes. AI tools aim to reduce regression cycles. (Ch 3, 4)

**self-healing tests** — AI-powered tests that automatically update when application code or UI changes, eliminating manual test maintenance. (Ch 4)

**vibe coding** — Karpathy's term for fully delegating code writing to AI: accept all suggestions, don't read diffs, copy-paste errors back. Safe for prototypes, dangerous for production. (Ch 8)

**vibe debugging** — The consequence of vibe coding: spending more time debugging AI-generated bugs than writing the code manually would have taken. (Ch 8)
