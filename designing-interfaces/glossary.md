# Glossary

**Accordion** — Vertically stacked panels that expand/collapse to show content, saving vertical space. (Ch3)

**Affordance** — A visual property that signals how an element can be used (e.g., a button looks pressable). (Ch1)

**Anticipatory interface** — A system that predicts user intent and acts proactively (e.g., suggesting next actions). (Ch12)

**Assistive interface** — Guides users step-by-step through complex tasks, often as a wizard or setup flow. (Ch12)

**Atomic Design** — Brad Frost's methodology: atoms → molecules → organisms → templates → pages. (Ch11)

**Bottom navigation** — Mobile navigation bar at the screen bottom, typically 3-5 tabs. (Ch8)

**Breadcrumbs** — Secondary navigation showing the current page's position in the site hierarchy. (Ch3)

**Card layout** — A content container with defined boundary, usually with shadow/border, grouping related info. (Ch4)

**Chunking** — Breaking information into small, meaningful groups to fit working memory limits. (Ch1)

**Command palette** — A keyboard-triggered overlay for searching and executing commands (Ctrl+K). (Ch5)

**Contextual navigation** — Links and actions offered based on the user's current context and task. (Ch3)

**Data table** — Tabular display of structured data with sortable columns, filters, and row actions. (Ch6)

**Design token** — A named atomic value (color, spacing, type scale) that enforces visual consistency. (Ch11)

**Design system** — A living collection of reusable components, patterns, and guidelines. (Ch11)

**Direct manipulation** — Interacting with on-screen objects as if they were physical (drag, resize, rotate). (Ch1, Ch5)

**Fitts's Law** — Time to acquire a target = distance / size. Larger, closer targets are faster. (Ch1)

**Flat navigation** — All pages accessible at the same level (typical in mobile apps with tab bars). (Ch3)

**F pattern / Z pattern** — Common eye-scanning patterns: F for text-heavy pages, Z for visual pages. (Ch4)

**Gestalt principles** — Proximity, similarity, closure, continuity, figure-ground — how humans group visual elements. (Ch4, Ch9)

**Grid system** — Column-based layout framework (typically 12-column) for consistent responsive design. (Ch10)

**Gulfs of execution/evaluation** — Don Norman's model of the gap between user intent and system feedback. (Ch1)

**Hamburger menu** — Icon (☰) representing a hidden navigation drawer; controversial for discoverability. (Ch3)

**Input validation** — Checking user input in real-time (inline) or on submission for correctness and format. (Ch7)

**Infinite scroll** — Continuous loading as user scrolls, suitable for discovery but poor for targeted browsing. (Ch6)

**Label placement** — Top-aligned (fastest scanning), left-aligned, right-aligned (slowest but space-efficient). (Ch7)

**Mental model** — User's internal understanding of how a system works, built from surface interaction. (Ch1)

**Miller's Law** — Working memory can hold 7±2 items; chunk to fit. (Ch1)

**Modal** — A child window requiring user action before returning to the parent. (Ch4)

**Natural user interface (NUI)** — Interaction through voice, gesture, touch rather than WIMP (windows, icons, menus, pointer). (Ch12)

**Pagination** — Numbered page navigation with previous/next, used for search results and lists. (Ch3, Ch6)

**Postel's Law** — Be liberal in what you accept, conservative in what you send. (Ch1, Ch7)

**Progressive disclosure** — Revealing advanced options only as needed to reduce complexity. (Ch3, Ch7)

**Progressive enhancement** — Building for baseline functionality first, then adding advanced features. (Ch4)

**Responsive design** — Layout adapts to viewport width via breakpoints, fluid grids, flexible images. (Ch4, Ch10)

**Stepper / Wizard** — Multi-step form broken into sequential steps with progress indication. (Ch3, Ch7)

**Tab bar** — Horizontal row of selectable panels or sections. (Ch3)

**Thumb zone** — The easily reachable screen area on mobile (bottom and center, not top corners). (Ch8)

**Tooltip** — A small popup with contextual help that appears on hover/focus. (Ch7)

**Visual hierarchy** — The arrangement of elements by visual weight to communicate importance. (Ch4, Ch9)

**Visual weight** — An element's perceived importance based on size, color, contrast, whitespace. (Ch9)
