# Chapter 2 — Organizing Content

## Core concepts
- Information architecture is the invisible structure users navigate to find content
- Content organization mirrors users' mental models of the domain
- Three main structures: hierarchical (tree), matrix (multi-attribute), and linear (sequential)
- Search and browse complement each other — most users use both
- Faceted navigation dominates e-commerce and rich content catalogs

## Frameworks introduced
- **Hierarchical organization** — Broad and shallow (5-7 top categories, max 3 levels deep) works best
- **Faceted navigation** — Multi-dimensional filtering with dynamic result updates; only show facets with results
- **Search + browse hybrid** — Real-time autocomplete + filtered results page; handles both known-item and exploratory searches
- **Card sorting** — Research method: users group items to reveal their mental model

## Key techniques
- **Label testing**: Test category labels with representative users; avoid jargon
- **Faceted filter design**: Show active filters as removable tags; preserve context when filters change
- **Search ranking**: Surface most-likely results first; support typos via Levenshtein or phonetic matching
- **AI-assisted organization**: Tagging, clustering, and auto-classification for large content sets
