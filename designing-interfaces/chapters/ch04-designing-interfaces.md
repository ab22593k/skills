# Chapter 4 — Organizing the Page

## Core concepts

- Visual hierarchy is the single most important layout principle: make important things look important
- Users scan in F pattern (text-heavy) or Z pattern (visual-heavy, less text)
- Whitespace is a design element, not wasted space — it creates grouping and breathing room
- Responsive layouts adapt content, not just dimensions: change structure at breakpoints
- Cards unify heterogeneous content into scannable containers that reflow naturally

## Frameworks introduced

- **Visual hierarchy** — Size, weight, color, position, whitespace determine what users see first
- **Gestalt principles** — Proximity (near = related), similarity (same style = same kind), closure (incomplete shapes are filled in), continuity (alignment creates perceived lines)
- **Card layout** — Consistent internal padding, subtle shadow/border, responsive grid reflow
- **Modal / Lightbox** — Focus attention on one task; use sparingly. Dialog: confirm action. Lightbox: focus on image/content.
- **Dashboard layout** — Grid of cards/charts with consistent header, filtering, and responsive breakouts
- **Progressive enhancement** — Core content first, enhanced interactivity layered on top

## Key techniques

- **Critical path check**: Identify the single most important thing on the page; make it visually dominant
- **Content inventory**: List all page elements, assign visual weight, check alignment against information hierarchy
- **Responsive breakpoints**: Mobile (320-480), tablet (768-1024), desktop (1280+) — adapt column count, not just margins
- **Z-pattern for landing**: Logo top-left, CTA bottom-right follows natural Z scanning
