# Glossary

**Accessibility by default** — Principle that Material components embed WCAG-compliant accessibility. Flutter: `Semantics` on all Material widgets. (→ ch01)

**Canonical layouts** — Reusable layout patterns per window size class: Feed, List-detail, Multi-pane. (→ ch07)

**Color role** — Semantic color assignment (primary, secondary, tertiary, surface, error). Flutter: `ColorScheme.primary`. (→ ch02)

**Color scheme** — Complete set of color roles for one brightness mode. Flutter: `ColorScheme` in `ThemeData`. (→ ch02)

**Container (color)** — Lighter/darker accent color used for component backgrounds. Flutter: `ColorScheme.primaryContainer`. (→ ch02)

**Content-based dynamic color** — Dynamic color from in-app content. Flutter: `PaletteGenerator` from `palette_generator` package. (→ ch02)

**Design token** — Single source-of-truth for a visual property. Flutter: mapped via `ThemeData`. (→ ch08)

**Dynamic color** — Full accessible palette from a single seed. Flutter: `ColorScheme.fromSeed()`. (→ ch02)

**Edge-to-edge** — Drawing behind system bars. Flutter: `SafeArea`, `MediaQuery.removePadding`. (→ ch07)

**Emphasized easing** — MD3's easing family. Flutter: `Curves.emphasized`, `.emphasizedDecelerate`, `.emphasizedAccelerate`. (→ ch05)

**Emphasized type** — Type styles with increased weight for hierarchy. Flutter: manual `TextStyle` override. (→ ch03)

**Expressive (M3 Expressive)** — May 2025 update: spring motion, updated shape scale, 35-shape library, new components. (→ ch10)

**Expressive shape library** — 35 decorative shapes for moments of delight. Flutter: approximated via custom `ClipPath`. (→ ch04)

**FAB (Floating Action Button)** — Primary action button. Flutter: `FloatingActionButton(.small/.large)`, `ExtendedFloatingActionButton`. (→ ch06)

**Google Fonts** — Flutter package for loading custom fonts with `google_fonts`. Replaces manual font asset setup. (→ ch03)

**InkWell / InkResponse** — Flutter widgets implementing MD3 state layer + ripple. (→ ch01)

**Interaction state** — enabled, disabled, hover, focused, pressed, dragged. Flutter: `WidgetState` enum. (→ ch01)

**LayoutBuilder** — Flutter widget that responds to parent constraints. Idiomatic tool for responsive layout. (→ ch07)

**Material Theme Builder** — Web/Figma tool exporting to Flutter-compatible Dart code. (→ ch10)

**MaterialStateProperty** — Flutter API for state-dependent theming values. Replaced `MaterialStateColor`. (→ ch06)

**PaletteGenerator** — Flutter package for extracting dominant colors from images for content-based dynamic color. (→ ch02)

**Seed color** — Single color driving the entire dynamic color system. Flutter: `ColorScheme.fromSeed(seedColor:)`. (→ ch02)

**Shape morphing** — Animating shape radius to communicate state. Flutter: `AnimatedContainer` + `Curves.emphasized`. (→ ch04)

**Spring-based motion** — Physics-driven animation. Flutter: `SpringDescription` + `SpringSimulation`. (→ ch05)

**State layer** — Opacity overlay on component container. Flutter: handled natively by `Material` widget. (→ ch01)

**Surface container** — Tonal elevation color roles. Flutter: `ColorScheme.surfaceContainerLow` → `.surfaceContainerHighest`. (→ ch04)

**TextTheme** — Flutter class holding 15+ `TextStyle` properties, mapped to M3 type scale. (→ ch03)

**ThemeData** — Flutter's centralized theme configuration class. Holds `ColorScheme`, `TextTheme`, component themes. (→ ch10)

**Tonal elevation** — Surface hierarchy via color, not shadows. Flutter: `ColorScheme.surfaceContainer*` family. (→ ch04)

**Tonal palette** — 13 tones of a single hue defining all color roles. Generated by `ColorScheme.fromSeed`. (→ ch02)

**Window size class** — Three breakpoints: compact (<600dp), medium (600–839dp), expanded (≥840dp). Flutter: detected via `LayoutBuilder`. (→ ch07)

**8dp spacing system** — M3 base grid unit. Flutter: define `EdgeInsets` constants in multiples of 8. (→ ch07)
